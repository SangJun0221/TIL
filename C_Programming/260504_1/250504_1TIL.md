# 260504_1 C언어 트러블슈팅: 반복 입력 구조에서 scanf 위치 오류로 인한 무한 루프

## 1. 문제 요약
정수를 반복해서 입력받아, `60점 이상인 점수의 합계`와 `개수`를 출력하는 프로그램 구현.

**[처리 조건]**
* 정수를 계속 입력받는다.
* 입력값이 `-1`이면 입력을 종료한다.
* `-1`은 계산에 포함하지 않는다.
* 입력값이 `60` 이상이면 합계에 더하고, 개수도 1 증가시킨다.
* 반복이 종료되면 합계와 개수를 출력한다.

**[입력 예시]**
```text
70
50
80
40
-1
````

**[출력 예시]**

```text
합계 : 150
개수 : 2
```

---

## 2. 초기 구현

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>

int main()
{
	int score;
	int count = 0;
	int sum = 0;

	scanf("%d", &score);

	for (;;) 
	{
		if (score == -1)
		{
			break;
		}
		else if (score >= 60)
		{
			count++;
			sum += score;
		}
	}

	printf("합계 : %d", sum);
	printf("개수 : %d", count);

	return 0;
}
```

---

## 3. 문제 상황

빌드 후 첫 번째 숫자를 입력하면, 이후 추가 입력이 되지 않는 것처럼 보였다.

처음에는 콘솔 입력 문제처럼 보였지만, 실제 원인은 반복문 내부에서 새로운 입력을 받지 않는 구조였다.

초기 코드에서는 `scanf("%d", &score);`가 반복문 밖에 있었다.
따라서 프로그램은 처음 입력한 값 하나만 `score`에 저장하고, 반복문 안에서는 그 값을 계속 재사용했다.

예를 들어 첫 입력으로 `70`을 넣으면:

```text
score = 70
```

그 이후 반복문 안에서 `score`는 다시 입력되지 않으므로 계속 `70`이다.

결과적으로:

* `score == -1` 조건은 계속 거짓
* `score >= 60` 조건은 계속 참
* `count++`, `sum += score`가 무한 반복
* 새 입력을 받을 기회가 없어 콘솔이 멈춘 것처럼 보임

즉, 문제는 입력창이 멈춘 것이 아니라 **같은 값을 반복 처리하는 무한 루프**였다.

## 4. 원인 분석

이번 문제의 핵심은 **반복 입력 문제에서는 `scanf`도 반복 대상**이라는 점이다.

초기 구조는 다음과 같았다.

```c
scanf("%d", &score);

for (;;) {
	// score 처리
}
```

이 구조는 입력을 한 번만 받고, 같은 값을 무한히 처리한다.

반복 입력 문제에서 올바른 구조는 다음과 같아야 한다.

```c
for (;;) {
	scanf("%d", &score);

	if (score == -1) {
		break;
	}

	if (score >= 60) {
		count++;
		sum += score;
	}
}
```

즉, 반복문 한 바퀴마다 다음 순서가 유지되어야 한다.

```text
입력 받기 -> 종료값인지 검사하기 -> 실제 처리 조건 검사하기 -> 합계와 개수 갱신하기
```

특히 `-1` 같은 sentinel 값은 입력 직후 바로 검사해야 한다.
그래야 종료용 데이터가 합계나 개수 계산에 섞이지 않는다.

## 5. 수정 과정

`scanf("%d", &score);`를 반복문 안으로 이동했다.

또한 출력 결과가 붙어 보이지 않도록 합계 출력 뒤에 줄바꿈 `\n`을 추가했다.

**[수정 전]**

```c
scanf("%d", &score);

for (;;) 
{
	if (score == -1)
	{
		break;
	}
	else if (score >= 60)
	{
		count++;
		sum += score;
	}
}
```

**[수정 후]**

```c
for (;;) 
{
	scanf("%d", &score);

	if (score == -1)
	{
		break;
	}
	else if (score >= 60)
	{
		count++;
		sum += score;
	}
}
```

## 6. 최종 코드 (Verified Code)

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>

int main()
{
	int score;
	int count = 0;
	int sum = 0;

	for (;;) 
	{
		scanf("%d", &score);

		if (score == -1)
		{
			break;
		}
		else if (score >= 60)
		{
			count++;
			sum += score;
		}
	}

	printf("합계 : %d\n", sum);
	printf("개수 : %d", count);

	return 0;
}
```

## 7. 핵심 인사이트 (Takeaway) & Action Item

반복 입력 문제에서 `scanf`는 단순 준비 코드가 아니라 **반복문 내부에서 매번 실행되어야 하는 핵심 로직**이다.

입력문이 반복문 밖에 있으면, 프로그램은 첫 번째 입력값만 계속 사용한다.
이 경우 조건이 종료 조건으로 바뀔 기회가 없기 때문에 무한 루프가 발생할 수 있다.

이번 문제에서 중요한 구조는 다음과 같다.

```text
입력 받기 -> 종료 조건 검사 -> 처리 조건 검사 -> 누적/카운트 갱신
```

특히 `-1`처럼 입력 종료를 의미하는 sentinel 값은 실제 데이터가 아니므로, 입력 직후 가장 먼저 걸러내야 한다.

**[다음부터 체크할 것]**

* [ ] 반복 입력 문제에서 `scanf`가 반복문 안에 있는지 먼저 확인하기
* [ ] 반복문 안에서 입력값이 매번 새로 갱신되는지 확인하기
* [ ] `-1` 같은 sentinel 값은 입력 직후 바로 검사하기
* [ ] 합계 문제는 `sum`, 개수 문제는 `count`를 분리해서 관리하기
* [ ] 출력이 붙어 보이지 않도록 필요한 곳에 `\n` 넣기
