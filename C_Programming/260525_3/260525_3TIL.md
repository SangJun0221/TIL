# 260525_3 C언어 트러블슈팅: 이차원 배열과 메뉴 반복 구조로 학생 점수 관리하기

## 1. 문제 요약
학생 최대 3명의 국어, 영어, 수학 점수를 저장하고, 메뉴를 통해 학생 추가와 전체 출력을 수행하는 프로그램 구현.

**[처리 조건]**
* 이차원 배열 `int score[3][3]`을 사용한다.
* 메뉴는 반복해서 출력한다.
* `1`을 입력하면 학생의 국어, 영어, 수학 점수를 추가한다.
* 학생은 최대 3명까지만 추가할 수 있다.
* 이미 3명이 추가된 상태에서 다시 추가하려 하면 `더 이상 추가할 수 없습니다.`를 출력한다.
* `2`를 입력하면 현재까지 추가된 학생들의 점수를 출력한다.
* `3`을 입력하면 프로그램을 종료한다.

**[출력 예시]**
```text
1. 학생 추가
2. 전체 출력
3. 종료
? 1
국어 영어 수학 입력 : 90 80 70

1. 학생 추가
2. 전체 출력
3. 종료
? 1
국어 영어 수학 입력 : 100 90 80

1. 학생 추가
2. 전체 출력
3. 종료
? 2
[0] 국어 : 90 영어 : 80 수학 : 70
[1] 국어 : 100 영어 : 90 수학 : 80
````

## 2. 초기 구현

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>

int main()
{
	for (;;)
	{
		int score[3][3];
		int i;
		int count = 0;
		int menu;

		printf("1. 학생 추가");
		printf("2. 전체 출력");
		printf("3. 종료 ");

		scanf("%d", &menu);

		if (menu == 1)
		{
			if (count == 3)
			{
				printf("더 이상 추가할 수 없습니다.");
			}
			else 
			{
				printf("국어 영어 수학 입력 : ");
				scanf("%d %d %d",
					&score[count][0],
					&score[count][1],
					&score[count][2]);

				count++;
			}
		}
		else if (menu == 2)
		{
			for (i = 0; i < count; i++)
			{
				printf("[%d]국어 : %d 영어 : %d 수학 :%d",
					i, score[i][0], score[i][1], score[i][2]);
			}
		}
		else if (menu == 3)
		{
			break;
		}
	}

	return 0;
}
```

## 3. 문제 상황

처음에는 `break`를 사용했을 때 반복문이나 `switch` 내부가 아니라는 오류가 발생했다.

원인은 메뉴형 프로그램에서 필요한 `for (;;)` 반복문을 처음에 빠뜨렸기 때문이다.
`break`는 반드시 `for`, `while`, `switch` 내부에서만 사용할 수 있다.

그 후 `for (;;)`를 추가했지만, 이번에는 `score`, `count`, `menu` 같은 주요 변수를 반복문 내부에 선언했다.

```c
for (;;)
{
	int score[3][3];
	int i;
	int count = 0;
	int menu;
	...
}
```

이 구조에서는 반복문이 한 바퀴 돌 때마다 `score` 배열과 `count`가 새로 만들어진다.
특히 `count`가 매번 `0`으로 초기화되기 때문에, 학생을 추가해도 다음 메뉴로 돌아오는 순간 기존 저장 상태를 추적할 수 없게 된다.

즉, 메뉴는 반복되어야 하지만, 저장 데이터와 학생 수는 반복될 때마다 초기화되면 안 된다.

## 4. 원인 분석

이번 문제의 핵심은 **반복되어야 하는 코드와 유지되어야 하는 데이터를 분리하는 것**이다.

메뉴형 프로그램에서는 다음 구조가 필요하다.

```text
변수 선언 및 초기화
-> for(;;)로 메뉴 반복
-> menu 입력
-> menu 값에 따라 학생 추가 / 전체 출력 / 종료
```

`score[3][3]`은 학생들의 점수를 저장하는 데이터 공간이다.

```text
score[학생번호][과목번호]
```

예를 들어:

```text
score[0][0] = 0번 학생 국어
score[0][1] = 0번 학생 영어
score[0][2] = 0번 학생 수학
```

`count`는 단순한 카운터가 아니라 두 가지 의미를 가진다.

```text
count = 현재 저장된 학생 수
count = 다음 학생이 저장될 행 번호
```

따라서 `count`는 반복문 내부에서 매번 `0`으로 초기화되면 안 된다.
프로그램이 종료될 때까지 계속 유지되어야 한다.

반복문 안에 들어가야 하는 것은 다음과 같다.

```text
메뉴 출력
메뉴 입력
menu 값에 따른 처리
```

반복문 밖에 있어야 하는 것은 다음과 같다.

```text
score 배열
count
menu
i
```

## 7. 핵심 인사이트 (Takeaway) & Action Item

메뉴형 프로그램에서는 `for (;;)`를 이용해 메뉴 출력과 입력 처리를 반복한다.

하지만 반복되는 것은 메뉴 처리이지, 저장 데이터가 아니다.
따라서 `score` 배열과 `count`는 반복문 밖에 선언해야 한다.

이번 문제의 핵심 구조는 다음과 같다.

```text
데이터 선언
-> 메뉴 반복
-> 학생 추가 시 score[count][과목번호]에 저장
-> count 증가
-> 전체 출력 시 i < count까지만 출력
-> 종료 선택 시 break
```

`count`는 현재 저장된 학생 수이면서 동시에 다음 학생이 저장될 행 번호다.

```text
count = 0 -> score[0][0], score[0][1], score[0][2]에 저장
count = 1 -> score[1][0], score[1][1], score[1][2]에 저장
count = 2 -> score[2][0], score[2][1], score[2][2]에 저장
count = 3 -> 더 이상 추가 불가
```

또한 `score[3][3]`에서 학생 인덱스는 `0, 1, 2`까지만 가능하다.
따라서 `count == 3`이면 추가를 막아야 한다.

**[다음부터 체크할 것]**

* [ ] 메뉴형 프로그램에서는 `for (;;)` 안에서 메뉴 출력, 입력, 처리를 반복하기
* [ ] `break`는 `for`, `while`, `switch` 내부에서만 사용할 수 있다는 점 기억하기
* [ ] 저장되어야 하는 데이터는 반복문 안에서 매번 초기화하지 않기
* [ ] `score[학생번호][과목번호]` 구조로 이차원 배열 해석하기
* [ ] `count`를 현재 학생 수이자 다음 저장 행 번호로 사용하기
* [ ] 학생 최대 수가 3명이면 `count == 3`일 때 추가 막기
* [ ] 전체 출력은 `i < count`까지만 반복하기
