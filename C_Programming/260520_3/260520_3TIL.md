# 260520_3 C언어 트러블슈팅: 배열 평균 계산에서 avg 계산 위치 분리하기

## 1. 문제 요약
정수 5개를 입력받아 배열에 저장한 뒤, 평균 이하인 수만 출력하는 프로그램 구현.

**[처리 조건]**
* 정수 5개를 입력받는다.
* 입력받은 값은 배열 `a[5]`에 저장한다.
* 입력값들의 합계 `sum`을 구한다.
* 평균 `avg`를 구한다.
* 배열을 다시 순회하면서 평균 이하인 값만 출력한다.
* 출력값은 공백으로 구분한다.

**[입력 예시]**
```text
30 20 30 40 25
````

**[출력 예시]**

```text
20 25
```

---

## 2. 초기 구현

```c
#define	_CRT_SECURE_NO_WARNINGS
#include <stdio.h>

int main()
{
	int a[5];
	int i;
	int avg = 0;
	int sum = 0;

	for (i = 0; i < 5; i++)
	{
		scanf("%d", &a[i]);

		sum += a[i];

		avg = sum / 5;
	}

	for (i = 0; i < 5; i++)
	{
		if (a[i] <= avg)
		{
			printf("%d ", a[i]);
		}
	}

	return 0;
}
```

---

## 3. 문제 상황

정수 5개를 입력받고 평균 이하인 수를 출력하는 구조는 어느 정도 맞았지만, 평균을 계산하는 위치가 부정확했다.

초기 코드에서는 입력을 받을 때마다 `sum`을 누적하고, 그 즉시 `avg = sum / 5;`를 실행했다.

```c
for (i = 0; i < 5; i++)
{
	scanf("%d", &a[i]);

	sum += a[i];

	avg = sum / 5;
}
```

이 구조에서는 입력값 5개가 모두 들어오기 전에 평균을 계속 계산하게 된다.

예를 들어 입력이 `30 20 30 40 25`라면 내부 흐름은 다음과 같다.

```text
1개 입력 후: sum = 30,  avg = 30 / 5 = 6
2개 입력 후: sum = 50,  avg = 50 / 5 = 10
3개 입력 후: sum = 80,  avg = 80 / 5 = 16
4개 입력 후: sum = 120, avg = 120 / 5 = 24
5개 입력 후: sum = 145, avg = 145 / 5 = 29
```

마지막에는 결과적으로 `avg`가 29가 되지만, 평균은 전체 합계가 완성된 뒤 한 번만 계산하는 것이 더 정확한 구조다.

---

## 4. 원인 분석

이번 문제의 핵심은 **합계 누적 단계와 평균 계산 단계를 분리하는 것**이다.

`sum`은 입력을 받으면서 누적해도 된다.

```c
scanf("%d", &a[i]);
sum += a[i];
```

하지만 `avg`는 전체 합계가 완성된 뒤 계산해야 한다.

```c
avg = sum / 5;
```

평균은 중간 입력값 기준으로 계산하는 값이 아니라, 5개 전체 입력값의 합계를 기준으로 계산하는 값이다.

따라서 올바른 흐름은 다음과 같다.

```text
입력 받기 + sum 누적 -> avg 계산 -> 평균 이하 값 출력
```

## 5. 수정 과정

처음에는 `avg = sum / 5;`를 입력 반복문 안에 두었다.

**[수정 전]**

```c
for (i = 0; i < 5; i++)
{
	scanf("%d", &a[i]);

	sum += a[i];

	avg = sum / 5;
}
```

이후 평균 계산식을 반복문 밖으로 이동했다.

**[수정 후]**

```c
for (i = 0; i < 5; i++)
{
	scanf("%d", &a[i]);

	sum += a[i];
}

avg = sum / 5;
```

이렇게 수정하면 정수 5개 입력이 모두 끝난 뒤, 완성된 `sum`을 기준으로 평균을 한 번만 계산한다.

그 다음 배열을 다시 순회하면서 평균 이하인 값만 출력한다.

```c
for (i = 0; i < 5; i++)
{
	if (a[i] <= avg)
	{
		printf("%d ", a[i]);
	}
}
```

## 6. 최종 코드 (Verified Code)

```c
#define	_CRT_SECURE_NO_WARNINGS
#include <stdio.h>

int main()
{
	int a[5];
	int i;
	int avg = 0;
	int sum = 0;

	for (i = 0; i < 5; i++)
	{
		scanf("%d", &a[i]);

		sum += a[i];
	}

	avg = sum / 5;

	for (i = 0; i < 5; i++)
	{
		if (a[i] <= avg)
		{
			printf("%d ", a[i]);
		}
	}

	return 0;
}
```

## 7. 핵심 인사이트 (Takeaway) & Action Item

배열 평균 문제에서는 **합계 계산과 평균 계산의 위치를 분리**해야 한다.

`sum`은 입력받으면서 누적해도 되지만, `avg`는 전체 입력값의 합계가 완성된 뒤 한 번만 계산해야 한다.

이번 문제의 핵심 구조는 다음과 같다.

```text
배열 입력 + 합계 누적 -> 평균 계산 -> 배열 재순회 -> 조건 출력
```

또한 `avg = sum / 5;`는 정수 나눗셈이므로 소수점은 버려진다.

예를 들어:

```text
145 / 5 = 29
```

따라서 평균 이하 조건은 `a[i] <= avg`로 검사한다.
