# 260520_2 C언어 트러블슈팅: 배열 역순 순회와 조건 출력

## 1. 문제 요약
정수 5개를 입력받아 배열에 저장한 뒤, `60 이상인 수`만 거꾸로 출력하는 프로그램 구현.

**[처리 조건]**
* 정수 5개를 입력받는다.
* 입력받은 값은 배열 `a[5]`에 저장한다.
* 배열을 뒤에서부터 앞으로 순회한다.
* 값이 `60` 이상인 경우만 출력한다.
* 출력값은 공백으로 구분한다.

**[입력 예시]**
```text
50 70 30 90 60
````

**[출력 예시]**

```text
60 90 70
```

---

## 2. 초기 구현

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>

int main()
{
	int a[5];
	int i;

	for (i = 0; i < 5; i++)
	{
		scanf("%d", &a[i]);
	}

	for (i = 4; i >= 0; i--)
	{
		if (a[i] >= 60)
		{
			printf("%d ", a[i]);
		}
	}

	return 0;
}
```

---

## 3. 문제 상황

이번 코드는 요구사항을 정상적으로 만족했다.

다만 이 유형에서 주의해야 할 핵심은 배열의 인덱스 범위다.

배열을 다음과 같이 선언하면:

```c
int a[5];
```

사용 가능한 인덱스는 `0`부터 `4`까지다.

```text
a[0], a[1], a[2], a[3], a[4]
```

따라서 역순으로 출력할 때는 `a[5]`부터 시작하면 안 되고, 마지막 인덱스인 `a[4]`부터 시작해야 한다.

---

## 4. 원인 분석

배열은 선언한 크기와 실제 인덱스 번호가 다르다.

```c
int a[5];
```

는 정수 5개를 저장할 수 있다는 뜻이지, `a[5]`까지 사용할 수 있다는 뜻이 아니다.

배열 크기가 5일 때 실제 인덱스는 다음과 같다.

```text
0, 1, 2, 3, 4
```

따라서 정방향 순회는 다음과 같다.

```c
for (i = 0; i < 5; i++)
```

역방향 순회는 다음과 같다.

```c
for (i = 4; i >= 0; i--)
```

즉, 배열을 거꾸로 출력할 때는 **배열 크기 - 1**에서 시작해야 한다.

이번 문제에서는 배열 크기가 5이므로 시작 인덱스는 `4`다.

---

## 5. 수정 과정

이번 코드는 별도의 로직 수정 없이 요구사항을 충족했다.

입력은 정방향으로 배열에 저장했다.

```c
for (i = 0; i < 5; i++)
{
	scanf("%d", &a[i]);
}
```

출력은 배열의 마지막 인덱스부터 첫 번째 인덱스까지 역순으로 순회했다.

```c
for (i = 4; i >= 0; i--)
{
	if (a[i] >= 60)
	{
		printf("%d ", a[i]);
	}
}
```

이때 조건문 `a[i] >= 60`을 함께 사용하여, 역순으로 순회하면서도 `60` 이상인 값만 출력하도록 했다.

## 6. 최종 코드 (Verified Code)

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>

int main()
{
	int a[5];
	int i;

	for (i = 0; i < 5; i++)
	{
		scanf("%d", &a[i]);
	}

	for (i = 4; i >= 0; i--)
	{
		if (a[i] >= 60)
		{
			printf("%d ", a[i]);
		}
	}

	return 0;
}
```

## 7. 핵심 인사이트 (Takeaway) & Action Item

배열 역순 출력의 핵심은 마지막 인덱스부터 첫 번째 인덱스까지 순회하는 것이다.

배열 크기가 `5`라면 마지막 인덱스는 `5`가 아니라 `4`다.

```text
배열 크기 5 → 마지막 인덱스 4
```

따라서 역순 반복문은 다음과 같이 작성한다.

```c
for (i = 4; i >= 0; i--)
```

일반화하면 다음과 같다.

```text
for (i = 배열크기 - 1; i >= 0; i--)
```

이번 문제의 핵심 구조는 다음과 같다.

```text
배열 입력 -> 마지막 인덱스부터 역순 순회 -> 조건 검사 -> 출력
```

* [ ] 크기가 `5`인 배열의 마지막 인덱스는 `4`라는 점 기억하기
* [ ] 역순 순회는 `배열크기 - 1`부터 시작하기
* [ ] 배열 입력 시 `scanf("%d", &a[i])` 형태인지 확인하기
* [ ] 역순 순회 중에도 조건 검사(`a[i] >= 60`)를 함께 적용할 수 있다는 점 기억하기
* [ ] 출력값이 붙지 않도록 `printf("%d ", a[i])`처럼 공백 넣기
