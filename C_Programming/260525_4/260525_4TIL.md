# 260525_4 C언어 트러블슈팅: 배열 데이터 관리에서 중복 검사 로직 이해하기

## 1. 문제 요약
일차원 배열을 사용하여 최대 3개의 데이터를 저장하고, 메뉴를 통해 데이터 추가와 전체 출력을 수행하는 프로그램 구현.

**[처리 조건]**
* 일차원 배열 `int a[3]`을 사용한다.
* 데이터는 최대 3개까지만 저장할 수 있다.
* 이미 존재하는 값은 추가할 수 없다.
* `1`을 입력하면 데이터를 추가한다.
* `3`을 입력하면 전체 데이터를 출력한다.
* `0`을 입력하면 프로그램을 종료한다.

**[실행 예시]**
```text
1. 데이터 추가
3. 전체 출력
0. 종료
? 1
? 5
데이터가 추가되었습니다.

1. 데이터 추가
3. 전체 출력
0. 종료
? 1
? 4
데이터가 추가되었습니다.

1. 데이터 추가
3. 전체 출력
0. 종료
? 1
? 5
이미 데이터가 존재합니다.

1. 데이터 추가
3. 전체 출력
0. 종료
? 3
5 4
````

---

## 2. 초기 구현

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>

int main()
{
	int a[3];
	int b;
	int i;
	int menu;
	int count = 0;

	for (;;)
	{
		printf("1. 데이터 추가\n");
		printf("2. 전체 출력\n");
		printf("3. 종료 \n");
		printf("? ");

		scanf("%d", &menu);

		if (menu == 1)
		{
			if (count == 3)
			{
				printf("더 이상 데이터를 추가할 수 없습니다.\n");
			}
			else
			{
				printf("? ");
				scanf("%d", &b);

				for (i = 0; i < count; i++)
				{
					if (a[i] == b)
						break;
				}

				if (i == count)
				{
					a[i] = b;
					printf("데이터가 추가되었습니다 \n");
					count++;
				}
				else
				{
					printf("이미 데이터가 존재합니다\n");
				}
			}
		}
		else if (menu == 2)
		{
			for (i = 0; i < count; i++)
			{
				printf("%d", a[i]);
			}
			printf("\n");
		}
		else if (menu == 3)
		{
			break;
		}
	}

	return 0;
}
```

## 3. 문제 상황

중복 검사 로직 자체는 맞게 작성했지만, 메뉴 번호와 출력 형식이 원문 요구사항과 일부 달랐다.

원문 메뉴는 다음과 같았다.

```text
1. 데이터 추가
3. 전체 출력
0. 종료
```

하지만 초기 구현에서는 다음처럼 작성했다.

```text
1. 데이터 추가
2. 전체 출력
3. 종료
```

또한 전체 출력에서 `printf("%d", a[i]);`로 작성하여 값들이 붙어서 출력될 수 있었다.

예를 들어 배열에 `5, 4, 6`이 저장되어 있으면 원래는 다음처럼 출력되어야 한다.

```text
5 4 6
```

하지만 공백이 없으면 다음처럼 출력될 수 있다.

```text
546
```

다만 이번 문제의 핵심인 **중복 검사 후 추가 여부 판단 로직**은 올바르게 작성되었다.

## 4. 핵심 로직 분석

이번 문제의 핵심은 새로 입력한 값 `b`가 이미 배열에 존재하는지 확인하는 것이다.

현재 저장된 데이터 개수는 `count`가 관리한다.

```c
int count = 0;
```

`count`는 두 가지 의미를 가진다.

```text
count = 현재 저장된 데이터 개수
count = 다음 데이터가 저장될 위치
```

예를 들어 현재 상태가 다음과 같다고 하자.

```text
count = 2
a[0] = 5
a[1] = 4
```

이때 새 값 `b`를 입력받으면, 기존 데이터와 비교해야 한다.

```c
for (i = 0; i < count; i++)
{
	if (a[i] == b)
		break;
}
```

이 반복문은 `a[0]`부터 `a[count - 1]`까지만 검사한다.

즉, 실제로 저장된 데이터만 검사한다.

## 5. `i == count`의 의미

이번 문제에서 가장 중요한 조건은 다음 코드다.

```c
if (i == count)
```

이 조건은 단순히 숫자가 같다는 뜻이 아니라, 다음 의미를 가진다.

```text
배열의 저장된 데이터들을 끝까지 검사했지만,
입력값 b와 같은 값을 찾지 못했다.
```

즉, **중복이 없다는 뜻**이다.

---

### 경우 1: 중복이 있는 경우

현재 배열 상태:

```text
count = 2
a[0] = 5
a[1] = 4
```

새 입력값:

```text
b = 5
```

중복 검사 흐름:

```text
i = 0
a[0] == b
5 == 5
중복 발견
break 실행
```

이때 `i`는 `0`에서 멈춘다.

```text
i = 0
count = 2
```

따라서:

```c
if (i == count)
```

는 거짓이다.

그래서 `else`로 가서 다음 메시지를 출력한다.

```c
printf("이미 데이터가 존재합니다.\n");
```

---

### 경우 2: 중복이 없는 경우

현재 배열 상태:

```text
count = 2
a[0] = 5
a[1] = 4
```

새 입력값:

```text
b = 6
```

중복 검사 흐름:

```text
i = 0
a[0] == b ?
5 == 6 → 거짓

i = 1
a[1] == b ?
4 == 6 → 거짓
```

끝까지 검사했지만 같은 값을 찾지 못했다.

반복문이 정상 종료되면 `i`는 `2`가 된다.

```text
i = 2
count = 2
```

따라서:

```c
if (i == count)
```

는 참이다.

이 말은 **중복이 없으므로 추가 가능**하다는 뜻이다.

그래서 다음 코드가 실행된다.

```c
a[i] = b;
printf("데이터가 추가되었습니다.\n");
count++;
```

이때 `i == count`이므로 `a[i]`는 곧 `a[count]`와 같다.

즉, 새 데이터는 다음 저장 위치에 들어간다.

원문 조건에 맞추기 위해 메뉴 번호를 수정했다.

**[수정 전]**

```c

printf("2. 전체 출력\n");
printf("3. 종료 \n");
```

**[수정 후]**

```c

printf("3. 전체 출력\n");
printf("0. 종료\n");
```

분기 조건도 원문에 맞게 수정한다.

**[수정 전]**

```c

	// 전체 출력
}

{
	break;
}
```

**[수정 후]**

```c

{
	// 전체 출력
}

	break;
}
```

전체 출력에서는 값 사이에 공백을 추가한다.

**[수정 전]**

```c

```

**[수정 후]**

```c
printf("%d ", a[i]);
```

## 8. 핵심 인사이트 (Takeaway)

이번 문제의 핵심은 **중복 검사 후 추가 여부를 판단하는 방식**이다.

중복 검사는 다음 구조로 처리한다.

```c
for (i = 0; i < count; i++)
{
	if (a[i] == b)
	{
		break;
	}
}
```

이 반복문은 현재 저장된 데이터만 검사한다.

검사 후:

```c
if (i == count)
```

이면 중복이 없다는 뜻이다.

왜냐하면 중복을 발견했다면 `break`로 중간에 빠져나왔을 것이고, 그 경우 `i`는 `count`보다 작은 값에서 멈췄을 것이기 때문이다.

따라서 이번 문제의 핵심 구조는 다음과 같다.

```text
새 값 입력
-> 현재 저장된 데이터만 검사
-> 중복 발견 시 break
-> i == count이면 중복 없음
-> 중복 없으면 a[count] 위치에 저장
-> count 증가
```

`count`는 단순한 개수가 아니라 **다음 저장 위치**이기도 하다.

```text
count = 0 -> a[0]에 저장
count = 1 -> a[1]에 저장
count = 2 -> a[2]에 저장
count = 3 -> 더 이상 저장 불가
```
