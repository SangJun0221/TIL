# 260525_2 C언어 트러블슈팅: 문자열에서 특정 문자 카운트하기

## 1. 문제 요약
문자열을 입력받아, 문자열 안에 있는 대문자 `'A'`의 개수를 출력하는 프로그램 구현.

**[처리 조건]**
* 문자열을 입력받는다.
* 입력 문자열은 `char str[10]`에 저장한다.
* 문자열의 끝 `'\0'`을 만나면 검사를 종료한다.
* 문자 `'A'`가 나올 때마다 `count`를 1 증가시킨다.
* 마지막에 `count`를 출력한다.

**[입력 예시]**
```text
AbCADA
````

**[출력 예시]**

```text
3
```

---

## 2. 초기 구현

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>

int main()
{
	char str[10];
	int i;
	int count = 0;

	scanf("%s", str);

	for (i = 0; i < 10; i++)
	{
		if (str[i] == '\0')
		{
			break;
		}

		if (str[i] == 'A')
		{
			count++;
		}
	}

	printf("%d", count);

	return 0;
}
```

---

## 3. 문제 상황

이번 코드는 요구사항을 정상적으로 만족했다.

다만 문자열 문제에서는 다음 세 가지를 헷갈리기 쉽다.

* 문자열의 끝을 나타내는 `'\0'`
* 문자 하나를 비교할 때 사용하는 작은따옴표 `'A'`
* 문자열 전체를 입력받을 때 사용하는 `scanf("%s", str);`

특히 문자열 배열은 실제 입력된 문자 뒤에 자동으로 `'\0'`이 들어가므로, 배열 전체 크기인 `10`만큼 무조건 검사하는 것이 아니라 `'\0'`을 만나면 검사를 중단해야 한다.

---

## 4. 원인 분석

C에서 문자열은 문자 배열로 저장된다.

예를 들어 입력값이 `AbCADA`라면 배열에는 다음처럼 저장된다.

```text
str[0] = 'A'
str[1] = 'b'
str[2] = 'C'
str[3] = 'A'
str[4] = 'D'
str[5] = 'A'
str[6] = '\0'
```

따라서 문자열을 검사할 때는 `str[0]`부터 시작해서 `'\0'`을 만나기 전까지만 확인해야 한다.

```c
if (str[i] == '\0')
{
	break;
}
```

이 조건은 문자열의 끝을 확인하는 역할을 한다.

그 다음 현재 문자가 `'A'`인지 검사한다.

```c
if (str[i] == 'A')
{
	count++;
}
```

여기서 중요한 점은 `'A'`와 `"A"`의 차이다.

```text
'A'  : 문자 하나
"A"  : 문자열
```

`str[i]`는 문자 하나이므로 `"A"`가 아니라 `'A'`와 비교해야 한다.

---

## 5. 수정 과정

이번 코드는 별도의 로직 수정 없이 정상 동작했다.

문자열 입력은 다음과 같이 작성했다.

```c
scanf("%s", str);
```

`str`은 배열 이름이며, 배열의 시작 주소를 의미하므로 문자열 입력에서는 `&`를 붙이지 않는다.

문자열 검사는 다음 순서로 처리했다.

```text
문자열 입력 -> '\0' 검사 -> 'A' 검사 -> count 증가 -> 최종 count 출력
```

문자열 끝을 먼저 검사한 뒤, 끝이 아닌 경우에만 `'A'`인지 확인했다.

## 7. 핵심 인사이트 (Takeaway) & Action Item

문자열 카운트 문제는 정수 배열 카운트 문제와 구조가 비슷하다.

정수 배열에서는 조건에 맞는 값을 찾으면 `count++`를 했다.

```c
if (a[i] >= 60)
{
	count++;
}
```

문자열에서는 특정 문자를 찾으면 `count++`를 한다.

```c
if (str[i] == 'A')
{
	count++;
}
```

다만 문자열은 끝을 나타내는 `'\0'`이 있으므로, 반드시 `'\0'` 전까지만 검사해야 한다.

이번 문제의 핵심 구조는 다음과 같다.

```text
문자열 입력 -> '\0' 전까지 순회 -> 특정 문자 검사 -> count 증가 -> count 출력
```

**[다음부터 체크할 것]**

* [ ] 문자열 입력은 `scanf("%s", str);` 형태로 작성하기
* [ ] 문자열 끝은 `'\0'`으로 판단하기
* [ ] `'\0'` 검사에는 `==`를 사용하기
* [ ] 문자 하나 비교는 `"A"`가 아니라 `'A'` 사용하기
* [ ] `str[i]`는 문자 하나이므로 출력이나 비교 시 `%c`, `'A'` 기준으로 생각하기
* [ ] 특정 문자를 세는 문제는 `if (str[i] == 문자) count++;` 구조로 접근하기
