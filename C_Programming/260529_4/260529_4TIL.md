# 260529_4 C언어 트러블슈팅: `strcmp()`와 논리 연산자로 복수 로그인 조건 처리하기

## 1. 문제 요약

사용자로부터 `id`와 `password`를 입력받아 로그인 성공 여부를 출력하는 프로그램 구현.

**[처리 조건]**

* `id`와 `password`를 문자열로 입력받는다.
* 다음 두 조건 중 하나라도 만족하면 `"로그인 성공"`을 출력한다.

  * `id`가 `"admin"`이고 `password`가 `"1234"`
  * `id`가 `"student"`이고 `password`가 `"2026"`
* 그 외의 경우에는 `"로그인 실패"`를 출력한다.
* 문자열 비교는 `strcmp()`를 사용한다.
* 문자열을 `==`로 비교하지 않는다.
* 여러 로그인 조합을 처리하기 위해 `&&`와 `||`를 함께 사용한다.

**[입력 예시 1]**

```text
ID? admin
Password? 1234
```

**[출력 예시 1]**

```text
로그인 성공
```

**[입력 예시 2]**

```text
ID? student
Password? 2026
```

**[출력 예시 2]**

```text
로그인 성공
```

**[입력 예시 3]**

```text
ID? admin
Password? 2026
```

**[출력 예시 3]**

```text
로그인 실패
```

---

## 2. 최종 코드

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <string.h>

int main()
{
	char id[50];
	char password[50];

	printf("ID? ");
	scanf("%s", id);

	printf("Password? ");
	scanf("%s", password);

	if ((strcmp("admin", id) == 0 && strcmp("1234", password) == 0)
		||
		(strcmp("student", id) == 0 && strcmp("2026", password) == 0))
	{
		printf("로그인 성공");
	}
	else
	{
		printf("로그인 실패");
	}

	return 0;
}
```

---

## 3. 핵심 로직 분석

이번 문제의 핵심은 문자열 비교 조건을 여러 개 조합하는 것이다.

C에서 문자열은 `==`로 비교하지 않는다.

```c
if (id == "admin")
```

위 방식은 문자열 내용 비교가 아니므로 사용하면 안 된다.

문자열 내용이 같은지 비교할 때는 `strcmp()`를 사용한다.

```c
strcmp("admin", id) == 0
```

`strcmp()`는 두 문자열이 같을 때 `0`을 반환한다.

따라서 문자열이 같은지 검사하려면 반드시 `== 0`까지 작성해야 한다.

---

## 4. `&&`와 `||` 조건 구성

이번 로그인 조건은 두 개의 로그인 조합 중 하나라도 맞으면 성공이다.

첫 번째 조합은 다음과 같다.

```text
id = "admin"
password = "1234"
```

코드로는 다음처럼 작성한다.

```c
strcmp("admin", id) == 0 && strcmp("1234", password) == 0
```

여기서 `&&`는 AND 조건이다.

즉, 아이디와 비밀번호가 둘 다 맞아야 한다.

두 번째 조합은 다음과 같다.

```text
id = "student"
password = "2026"
```

코드로는 다음처럼 작성한다.

```c
strcmp("student", id) == 0 && strcmp("2026", password) == 0
```

이번 문제에서는 두 조합 중 하나라도 맞으면 로그인 성공이므로 두 조건을 `||`로 연결한다.

```c
(strcmp("admin", id) == 0 && strcmp("1234", password) == 0)
||
(strcmp("student", id) == 0 && strcmp("2026", password) == 0)
```

여기서 `||`는 OR 조건이다.

즉, 왼쪽 로그인 조합이 맞거나 오른쪽 로그인 조합이 맞으면 전체 조건이 참이 된다.

---

## 5. 괄호를 사용하는 이유

이번 조건문에서는 `&&`와 `||`가 함께 사용된다.

```c
if ((strcmp("admin", id) == 0 && strcmp("1234", password) == 0)
	||
	(strcmp("student", id) == 0 && strcmp("2026", password) == 0))
```

각 로그인 조합을 괄호로 묶으면 조건의 의미가 명확해진다.

```text
(admin 아이디 && admin 비밀번호)
||
(student 아이디 && student 비밀번호)
```

괄호 없이도 연산자 우선순위에 따라 동작할 수 있지만, 조건이 길어질수록 실수 가능성이 커진다.

따라서 `&&`와 `||`가 섞일 때는 각 조건 묶음을 괄호로 감싸는 것이 안전하다.

---

## 6. 실행 흐름

입력이 다음과 같다고 하자.

```text
ID? admin
Password? 1234
```

조건문에서는 다음 비교가 수행된다.

```c
strcmp("admin", id) == 0
```

`id`가 `"admin"`이므로 참이다.

```c
strcmp("1234", password) == 0
```

`password`가 `"1234"`이므로 참이다.

따라서 첫 번째 로그인 조합이 참이 되고, 전체 조건도 참이 된다.

결과:

```text
로그인 성공
```

반대로 입력이 다음과 같다면:

```text
ID? admin
Password? 2026
```

첫 번째 조합에서는 아이디는 맞지만 비밀번호가 틀린다.

두 번째 조합에서는 비밀번호는 맞지만 아이디가 틀린다.

따라서 두 조합 모두 성립하지 않으므로 결과는 다음과 같다.

```text
로그인 실패
```

## 7. 핵심 인사이트

이번 문제는 `strcmp()`를 이용한 문자열 비교와 논리 연산자 조합을 연습하는 문제였다.

핵심은 다음과 같다.

```text
문자열 비교는 ==가 아니라 strcmp() == 0으로 한다.
아이디와 비밀번호가 둘 다 맞아야 하는 조건은 &&로 연결한다.
여러 로그인 조합 중 하나라도 맞으면 되는 조건은 ||로 연결한다.
```

이번 문제의 조건식은 다음 구조로 정리할 수 있다.

```text
(admin && 1234) || (student && 2026)
```

C 코드로는 다음과 같다.

```c
if ((strcmp("admin", id) == 0 && strcmp("1234", password) == 0)
	||
	(strcmp("student", id) == 0 && strcmp("2026", password) == 0))
```

문자열 조건이 여러 개일 때는 각 조합을 괄호로 묶어 작성하면 로직을 더 안전하게 관리할 수 있다.
