# 260529_3 C언어 트러블슈팅: `strcmp()`로 문자열 로그인 조건 비교하기

## 1. 문제 요약

사용자로부터 `id`와 `password`를 입력받아 로그인 성공 여부를 출력하는 프로그램 구현.

**[처리 조건]**

* `id`와 `password`를 문자열로 입력받는다.
* `id`가 `"student"`이고 `password`가 `"2026"`이면 `"로그인 성공"`을 출력한다.
* 둘 중 하나라도 다르면 `"로그인 실패"`를 출력한다.
* 문자열 비교는 `strcmp()`를 사용한다.
* 문자열을 `==`로 비교하지 않는다.

**[입력 예시 1]**

```text
ID? student
Password? 2026
```

**[출력 예시 1]**

```text
로그인 성공
```

**[입력 예시 2]**

```text
ID? student
Password? 1234
```

**[출력 예시 2]**

```text
로그인 실패
```

---

## 2. 최종 코드

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <string.h>

int main()
{
	char id[50];
	char password[50];

	printf("ID? ");
	scanf("%s", id);

	printf("Password? ");
	scanf("%s", password);

	if (strcmp("student", id) == 0 && strcmp("2026", password) == 0)
	{
		printf("로그인 성공");
	}
	else
	{
		printf("로그인 실패");
	}

	return 0;
}
```

---

## 3. 핵심 로직 분석

이번 문제의 핵심은 문자열 비교 방식이다.

정수는 다음처럼 `==`로 비교할 수 있다.

```c
if (a == 10)
{
	// 처리
}
```

하지만 문자열은 다음처럼 비교하면 안 된다.

```c
if (id == "student")
{
	// 잘못된 문자열 비교 방식
}
```

C에서 문자열은 문자 배열이므로, 문자열의 내용이 같은지 비교할 때는 `strcmp()`를 사용해야 한다.

```c
strcmp("student", id)
```

`strcmp()`는 두 문자열이 같으면 `0`을 반환한다.

따라서 문자열이 같은지 검사하려면 다음처럼 작성한다.

```c
strcmp("student", id) == 0
```

---

## 4. 로그인 조건 구성

이번 로그인 성공 조건은 두 가지를 모두 만족해야 한다.

```text
id가 "student"와 같아야 한다.
password가 "2026"과 같아야 한다.
```

따라서 조건문은 다음과 같이 작성한다.

```c
if (strcmp("student", id) == 0 && strcmp("2026", password) == 0)
```

여기서 `&&`는 AND 조건이다.

즉, 왼쪽 조건과 오른쪽 조건이 모두 참이어야 전체 조건이 참이 된다.

```text
id 일치 && password 일치 → 로그인 성공
id 일치 && password 불일치 → 로그인 실패
id 불일치 && password 일치 → 로그인 실패
id 불일치 && password 불일치 → 로그인 실패
```

---

## 5. `strcmp()` 결과 해석

`strcmp()`의 결과는 다음처럼 해석한다.

```text
strcmp(문자열1, 문자열2) == 0  → 두 문자열이 같다
strcmp(문자열1, 문자열2) != 0  → 두 문자열이 다르다
```

예를 들어:

```c
strcmp("student", "student")
```

는 두 문자열이 같으므로 `0`을 반환한다.

반면:

```c
strcmp("student", "admin")
```

은 두 문자열이 다르므로 `0`이 아닌 값을 반환한다.

따라서 로그인 검사에서는 반드시 `== 0`까지 작성해야 한다.

---

## 6. `string.h`가 필요한 이유

`strcmp()`는 문자열 처리 함수이므로 다음 헤더가 필요하다.

```c
#include <string.h>
```

이 헤더를 포함해야 `strcmp()`를 사용할 수 있다.

문자열 관련 함수들은 보통 `string.h`에 포함되어 있다.

```text
strcmp()  = 문자열 비교
strcpy()  = 문자열 복사
strcat()  = 문자열 연결
strncat() = 지정한 길이만큼 문자열 연결
```

## 7. 핵심 인사이트

이번 문제는 문자열 로그인 조건을 처리하면서 `strcmp()`의 사용법을 확인하는 문제였다.

핵심은 다음과 같다.

```text
문자열 비교는 ==가 아니라 strcmp()를 사용한다.
strcmp()는 두 문자열이 같으면 0을 반환한다.
두 조건이 모두 맞아야 하면 &&를 사용한다.
```

이번 문제의 로그인 성공 조건은 다음 한 줄로 정리된다.

```c
strcmp("student", id) == 0 && strcmp("2026", password) == 0
```

즉, `id`와 `password`가 모두 정확히 일치할 때만 로그인 성공이 출력된다.
