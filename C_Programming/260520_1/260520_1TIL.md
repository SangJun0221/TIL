# 260520_1 C언어 트러블슈팅: 배열 카운트 문제에서 출력 위치와 조건 범위 구분하기

## 1. 문제 요약
정수 5개를 입력받아 배열에 저장한 뒤, `60 이상인 수`와 `60 미만인 수`의 개수를 각각 출력하는 프로그램 구현.

**[처리 조건]**
* 정수 5개를 입력받는다.
* 입력받은 값은 배열 `a[5]`에 저장한다.
* 배열을 순회하면서 `60` 이상이면 `pass`를 1 증가시킨다.
* `60` 미만이면 `fail`을 1 증가시킨다.
* 배열 전체 검사가 끝난 뒤 최종 개수를 출력한다.

**[입력 예시]**
```text
70 50 80 30 60
````

**[출력 예시]**

```text
60 이상 : 3
60 미만 : 2
```

---

## 2. 초기 구현

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>

int main()
{
	int a[5];
	int pass = 0;
	int fail = 0;

	for (int i = 0; i < 5; i++)
	{
		scanf("%d", &a[i]);
	}

	for (int i = 0; i < 5; i++)
	{
		if (a[i] >= 60)
		{
			pass++;
		}
		else
		{
			fail++;
		}

		printf("60이상 : %d\n", pass);
		printf("60이하 : %d", fail);
	}

	return 0;
}
```

---

## 3. 문제 상황

배열 입력과 카운트 로직 자체는 어느 정도 맞았지만, 출력 위치와 출력 문구에 문제가 있었다.

초기 코드에서는 `printf`가 두 번째 `for`문 안에 들어가 있었다.

```c
for (int i = 0; i < 5; i++)
{
	if (a[i] >= 60)
	{
		pass++;
	}
	else
	{
		fail++;
	}

	printf("60이상 : %d\n", pass);
	printf("60이하 : %d", fail);
}
```

이 구조에서는 배열 원소를 하나 검사할 때마다 현재까지의 카운트가 출력된다.
즉, 최종 결과를 한 번 출력하는 것이 아니라 중간 결과가 5번 출력되는 문제가 발생한다.

또한 `fail`은 `60 이하`가 아니라 `60 미만`의 개수를 의미한다.
조건문에서 `60`은 `a[i] >= 60`에 포함되므로 `pass`에 들어간다.

따라서 `else`에 해당하는 범위는 `60 이하`가 아니라 `60 미만`이다.

---

## 4. 원인 분석

이번 문제의 핵심은 **카운트 처리와 최종 출력의 위치를 분리하는 것**이다.

카운트 문제에서는 반복문 안에서 개수를 갱신하고, 반복문이 모두 끝난 뒤 최종 결과를 출력해야 한다.

올바른 흐름은 다음과 같다.

```text
배열 입력 -> 배열 순회 -> 조건에 따라 pass/fail 카운트 -> 최종 결과 출력
```

즉, 출력은 카운트 반복문이 끝난 뒤에 있어야 한다.

또한 조건의 반대 범위를 정확히 이해해야 한다.

```c
if (a[i] >= 60)
{
	pass++;
}
else
{
	fail++;
}
```

여기서 `else`는 `a[i] >= 60`이 거짓인 경우다.

따라서 `else`의 범위는 다음과 같다.

```text
a[i] < 60
```

즉, `fail`은 `60 미만`의 개수다.

## 7. 핵심 인사이트 (Takeaway) & Action Item

배열 카운트 문제에서는 **처리 반복문과 출력 위치를 분리**해야 한다.

반복문 안에서는 각 원소를 검사하며 카운트만 갱신하고, 최종 출력은 반복문이 끝난 뒤 한 번만 수행해야 한다.

이번 문제의 핵심 구조는 다음과 같다.

```text
입력 반복문 -> 처리 반복문 -> 최종 출력
```

또한 조건문의 `else`가 실제로 어떤 범위를 의미하는지 정확히 해석해야 한다.

```c
if (a[i] >= 60)
```

의 반대는:

```text
a[i] < 60
```

이다.

따라서 `60 이상`의 반대는 `60 이하`가 아니라 **`60 미만`**이다.

* [ ] 카운트 변수(`pass`, `fail`)를 0으로 초기화했는지 확인하기
* [ ] 카운트 결과 출력은 반복문 밖에서 하는지 확인하기
* [ ] `if` 조건의 반대 범위를 정확히 해석하기
* [ ] `>= 60`의 반대는 `< 60`이라는 점 기억하기
* [ ] 출력 문구가 실제 조건 범위와 일치하는지 확인하기
