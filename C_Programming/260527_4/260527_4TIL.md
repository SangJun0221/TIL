# 260527_4 C언어 트러블슈팅: 문자열 배열을 함수에 전달하여 대문자 개수 반환하기

## 1. 문제 요약
문자열을 입력받아, 문자열 안에 있는 대문자 알파벳의 개수를 출력하는 프로그램 구현.

**[처리 조건]**
* 문자열은 `char str[100]`에 저장한다.
* 대문자 개수를 세는 함수 `upper_count()`를 작성한다.
* 함수는 문자열 배열을 매개변수로 받는다.
* 함수 안에서는 출력하지 않는다.
* 대문자의 개수를 `return`한다.
* `main()`에서 함수 결과를 출력한다.

**[입력 예시]**
```text
aBCdEF
````

**[출력 예시]**

```text
4
```

---

## 2. 초기 구현

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>

int upper_count(char str[])
{
	int count = 0;
	int i = 0;

	while (str[i] != '\0')
	{
		if(str[i] >= 'A' && str[i] <= 'Z')
		{
			count++;
		}
		i++;
	}

	return count;
}

int main()
{
	char str[100];
	int result;

	printf("? ");
	scanf("%s", &str);

	result = upper_count(str);

	printf("%d", result);

	return 0;
}
```

---

## 3. 문제 상황

`upper_count()` 함수의 내부 로직은 정상적으로 작성했다.

문자열을 `i`로 한 글자씩 순회하면서 `'\0'` 전까지 검사하고, 현재 문자가 대문자이면 `count++`를 수행했다.

```c
while (str[i] != '\0')
{
	if(str[i] >= 'A' && str[i] <= 'Z')
	{
		count++;
	}
	i++;
}
```

하지만 `main()`에서 문자열을 입력받을 때 다음과 같이 작성했다.

```c
scanf("%s", &str);
```

정수 입력과 문자열 입력의 주소 전달 방식을 혼동한 것이 문제였다.

---

## 4. 원인 분석

정수 하나를 입력받을 때는 변수의 주소를 넘겨야 하므로 `&`를 사용한다.

```c
int a;
scanf("%d", &a);
```

하지만 문자열 배열은 다르다.

```c
char str[100];
```

에서 `str`은 배열 이름이고, 문자열 입력에서는 배열의 시작 주소처럼 사용된다.

따라서 문자열 입력은 다음과 같이 작성한다.

```c
scanf("%s", str);
```

즉, 정리하면 다음과 같다.

```text
정수 입력: scanf("%d", &a);
문자열 입력: scanf("%s", str);
```

`&str`을 쓰면 의도한 문자열 시작 위치 전달 방식과 다르므로, 초보 단계에서는 문자열 입력 시 `str`만 쓰는 것으로 고정하는 것이 안전하다.

## 5. 수정 과정

문자열 입력 부분에서 `&str`을 `str`로 수정했다.

**[수정 전]**

```c
scanf("%s", &str);
```

**[수정 후]**

```c
scanf("%s", str);
```

대문자 개수 계산 함수는 그대로 유지했다.

```c
int upper_count(char str[])
{
	int count = 0;
	int i = 0;

	while (str[i] != '\0')
	{
		if (str[i] >= 'A' && str[i] <= 'Z')
		{
			count++;
		}

		i++;
	}

	return count;
}
```

## 7. 핵심 인사이트

이번 문제의 핵심은 **문자열 배열을 함수에 전달하고, 함수에서 조건에 맞는 문자를 세어 반환하는 구조**다.

`upper_count()` 함수는 출력하지 않고, 대문자 개수만 계산해서 `return`한다.

```c
return count;
```

`main()`은 문자열을 입력받고, 함수 결과를 받아 출력한다.

```c
result = upper_count(str);
printf("%d", result);
```

역할은 다음처럼 분리된다.

```text
upper_count() = 문자열 검사 + 대문자 개수 계산 + return
main()        = 문자열 입력 + 함수 호출 + 결과 출력
```

또한 문자열을 순회할 때는 `i`가 현재 검사 위치를 나타내고, `count`는 조건을 만족한 문자의 개수를 나타낸다.

```text
i     = 현재 검사 중인 문자 위치
count = 대문자 개수
```

문자열의 끝은 `'\0'`으로 판단한다.

```c
while (str[i] != '\0')
```

대문자 조건은 다음과 같이 작성한다.

```c
if (str[i] >= 'A' && str[i] <= 'Z')
```

이번 문제에서 가장 중요한 구분은 다음이다.

```text
정수 입력에는 & 사용
문자열 입력에는 배열 이름 str 사용
```
