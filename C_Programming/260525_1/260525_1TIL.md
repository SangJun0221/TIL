# 260525_1 C언어 트러블슈팅: 문자열 역순 출력에서 `'\0'` 검사와 `=` / `==` 구분하기

## 1. 문제 요약
문자열을 입력받아 거꾸로 출력하되, 그중 `대문자 알파벳`만 출력하는 프로그램 구현.

**[처리 조건]**
* 문자열을 입력받는다.
* 입력 문자열의 최대 길이는 9글자라고 가정한다.
* 문자열의 끝은 `'\0'`으로 판단한다.
* 문자열 길이를 구한 뒤, 뒤에서부터 앞으로 순회한다.
* 대문자 알파벳(`A` ~ `Z`)인 문자만 출력한다.

**[입력 예시]**
```text
aBCdE
````

**[출력 예시]**

```text
ECB
```

---

## 2. 초기 구현

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>

int main()
{
	char str[10];
	int i;
	int count = 0;

	scanf("%s", str);

	for (i = 0; i < 10; i++)
	{
		count++;
	}

	for (i = count - 1; i >= 0; i--)
	{
		if (str[i] >= 'A' && str[i] <= 'Z')
			printf("%c", str[i]);
	}

	return 0;
}
```

---

## 3. 문제 상황

처음에는 문자열 길이를 구할 때 `'\0'` 검사를 하지 않고, 배열 크기인 `10`만큼 무조건 `count++`를 했다.

```c
for (i = 0; i < 10; i++)
{
	count++;
}
```

이렇게 작성하면 실제 문자열 길이가 아니라 배열 크기 전체를 길이처럼 취급하게 된다.

예를 들어 입력이 `aBCdE`라면 실제 문자열 구조는 다음과 같다.

```text
str[0] = 'a'
str[1] = 'B'
str[2] = 'C'
str[3] = 'd'
str[4] = 'E'
str[5] = '\0'
```

실제 문자열 길이는 `5`인데, 초기 코드에서는 `count`가 `10`이 된다.

그 결과 역순 출력 시 `str[9]`, `str[8]`, `str[7]`처럼 실제 문자열이 아닌 배열 공간까지 검사하게 된다.

---

## 4. 원인 분석

C 문자열은 문자 배열의 끝에 `'\0'`이라는 널 문자를 사용해 문자열의 끝을 표시한다.

따라서 문자열 길이를 직접 셀 때는 배열 크기만큼 무조건 세는 것이 아니라, `'\0'`을 만날 때까지 세어야 한다.

올바른 길이 계산 구조는 다음과 같다.

```c
for (i = 0; i < 10; i++)
{
	if (str[i] == '\0')
	{
		break;
	}

	count++;
}
```

여기서 중요한 점은 `=`와 `==`를 구분하는 것이다.

```c
str[i] = '\0'
```

위 코드는 비교가 아니라 대입이다.
즉, `str[i]`에 `'\0'`을 직접 넣어 문자열을 끊어버린다.

반면 아래 코드는 비교다.

```c
str[i] == '\0'
```

이 코드는 `str[i]`가 문자열 끝인지 확인하는 조건식이다.

따라서 `'\0'`을 검사할 때는 반드시 `==`를 사용해야 한다.

## 5. 수정 과정

문자열 길이를 계산하는 반복문에 `'\0'` 검사를 추가했다.

**[수정 전]**

```c
for (i = 0; i < 10; i++)
{
	count++;
}
```

**[수정 후]**

```c
for (i = 0; i < 10; i++)
{
	if (str[i] == '\0')
	{
		break;
	}

	count++;
}
```

그 후 역순 반복문은 `count - 1`부터 시작하도록 유지했다.

```c
for (i = count - 1; i >= 0; i--)
{
	if (str[i] >= 'A' && str[i] <= 'Z')
		printf("%c", str[i]);
}
```

문자열 길이가 `5`라면 마지막 실제 문자의 인덱스는 `4`이므로, `count - 1`부터 시작하는 것이 맞다.

## 6. 최종 코드 (Verified Code)

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>

int main()
{
	char str[10];
	int i;
	int count = 0;

	scanf("%s", str);

	for (i = 0; i < 10; i++)
	{
		if (str[i] == '\0')
		{
			break;
		}

		count++;
	}

	for (i = count - 1; i >= 0; i--)
	{
		if (str[i] >= 'A' && str[i] <= 'Z')
			printf("%c", str[i]);
	}

	return 0;
}
```

## 7. 핵심 인사이트 (Takeaway) & Action Item

문자열 배열에서는 실제 글자 뒤에 `'\0'`이 들어간다.
따라서 문자열 길이를 직접 계산할 때는 배열 전체 크기가 아니라 `'\0'`을 만나기 전까지 세어야 한다.

이번 문제의 핵심 구조는 다음과 같다.

```text
문자열 입력 -> '\0' 전까지 길이 계산 -> count - 1부터 역순 순회 -> 대문자만 출력
```

또한 `=`와 `==`의 차이를 반드시 구분해야 한다.

```text
=   : 대입, 값을 넣는다
==  : 비교, 같은지 확인한다
```

`str[i] = '\0'`처럼 작성하면 문자열을 검사하는 것이 아니라 해당 위치에 널 문자를 넣어버린다.
이 경우 문자열이 중간에서 끊기거나, 첫 글자부터 문자열이 끝난 것으로 처리될 수 있다.

대문자 조건은 다음처럼 작성한다.

```c
if (str[i] >= 'A' && str[i] <= 'Z')
```

문자 하나를 출력할 때는 `%s`가 아니라 `%c`를 사용한다.

```c
printf("%c", str[i]);
```
