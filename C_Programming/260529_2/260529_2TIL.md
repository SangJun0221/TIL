# 260529_2 C언어 트러블슈팅: `strncat`과 `strcat`으로 임시 비밀번호 생성하기

## 1. 문제 요약

사용자로부터 `id`와 `birth`를 입력받아 임시 비밀번호를 생성하는 프로그램 구현.

**[처리 조건]**

* `id`는 문자열로 입력받는다.
* `birth`는 생년월일 문자열로 입력받는다.
* 비밀번호는 `id`의 앞 2글자 + `"_"` + `birth`의 앞 4글자로 만든다.
* 문자열 처리 함수 `strncat()`과 `strcat()`을 사용한다.
* 최종 비밀번호를 출력한다.

**[입력 예시]**

```text
ID? sangjun
Birthdate? 020427
```

**[출력 예시]**

```text
sa_0204
```

---

## 2. 최종 코드

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <string.h>

int main()
{
	char id[50];
	char birth[9];
	char password[8] = "";

	printf("ID? ");
	scanf("%s", id);

	printf("Birthdate? ");
	scanf("%s", birth);

	strncat(password, id, 2);
	strcat(password, "_");
	strncat(password, birth, 4);

	printf("%s", password);

	return 0;
}
```

---

## 3. 핵심 로직 분석

이번 문제의 핵심은 여러 문자열 조각을 하나의 문자열로 이어 붙이는 것이다.

최종 비밀번호 형식은 다음과 같다.

```text
id 앞 2글자 + "_" + birth 앞 4글자
```

예를 들어 입력값이 다음과 같다면:

```text
id = "sangjun"
birth = "020427"
```

각 단계는 다음처럼 진행된다.

```c
strncat(password, id, 2);
```

`id`의 앞 2글자만 `password` 뒤에 붙인다.

```text
password = "sa"
```

그다음:

```c
strcat(password, "_");
```

문자열 `"_"` 전체를 뒤에 붙인다.

```text
password = "sa_"
```

마지막으로:

```c
strncat(password, birth, 4);
```

`birth`의 앞 4글자만 뒤에 붙인다.

```text
password = "sa_0204"
```

최종적으로 출력되는 값은 다음과 같다.

```text
sa_0204
```

---

## 4. `password[8]`의 크기 계산

이번 문제에서는 최종 비밀번호가 총 7글자다.

```text
id 앞 2글자 = 2
"_" = 1
birth 앞 4글자 = 4
```

따라서 실제 문자 개수는 다음과 같다.

```text
2 + 1 + 4 = 7
```

하지만 C 문자열은 마지막에 문자열 끝을 나타내는 `'\0'`이 필요하다.

그래서 배열 크기는 최소 8칸이 필요하다.

```text
실제 문자 7개 + '\0' 1개 = 8칸
```

따라서 다음 선언은 적절하다.

```c
char password[8] = "";
```

---

## 5. `password`를 빈 문자열로 초기화하는 이유

```c
char password[8] = "";
```

`strcat()`과 `strncat()`은 기존 문자열 뒤에 새로운 문자열을 붙이는 함수다.

따라서 처음에 `password`가 정상적인 빈 문자열 상태여야 한다.

만약 `password`를 초기화하지 않으면 배열 안에 쓰레기값이 들어 있을 수 있고, 그 상태에서 문자열을 붙이면 결과가 예측하기 어려워진다.

즉, 문자열을 이어 붙일 목적이라면 시작 문자열을 빈 문자열로 초기화해야 한다.

```c
char password[8] = "";
```

이 초기화가 있어야 이후 코드가 안전하게 동작한다.

---

## 6. `strncat()`과 `strcat()`의 차이

이번 문제에서는 두 종류의 문자열 연결 함수를 사용했다.

```c
strncat(password, id, 2);
```

`strncat()`은 지정한 글자 수만큼만 붙인다.

```text
id의 앞 2글자만 붙이기
```

반면:

```c
strcat(password, "_");
```

`strcat()`은 문자열 전체를 붙인다.

```text
"_" 전체 붙이기
```

정리하면 다음과 같다.

```text
strncat() = 문자열 일부만 붙이기
strcat()  = 문자열 전체 붙이기
```

이번 문제에서는 `id`와 `birth`는 일부만 사용하고, `"_"`는 전체를 사용하므로 두 함수를 함께 사용했다.

## 7. 핵심 인사이트

이번 문제는 문자열을 직접 조립하는 방식의 기초를 연습하는 문제였다.

핵심 구조는 다음과 같다.

```text
빈 문자열 준비
-> id 앞 2글자 붙이기
-> "_" 붙이기
-> birth 앞 4글자 붙이기
-> 최종 문자열 출력
```

중요한 점은 `strcat()`과 `strncat()`은 기존 문자열 뒤에 붙이는 함수이므로, 결과를 저장할 배열이 먼저 정상적인 문자열 상태여야 한다는 것이다.

따라서 다음 초기화가 필요하다.

```c
char password[8] = "";
```

또한 문자열 배열 크기를 정할 때는 실제 출력될 문자 개수만 계산하면 안 된다.

C 문자열은 항상 마지막에 `'\0'`이 필요하므로, 배열 크기는 다음처럼 계산해야 한다.

```text
필요한 배열 크기 = 실제 문자 개수 + 1
```

이번 문제에서는 실제 문자가 7개이므로 `password[8]`이 필요하다.
