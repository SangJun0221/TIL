# 260529_1 C언어 트러블슈팅: void 함수와 포인터로 여러 결과 전달하기

## 1. 문제 요약

두 정수 `a`, `b`를 입력받아 합과 차를 구하는 프로그램 구현.

**[처리 조건]**

* `main()` 함수에서 사용자로부터 두 정수 `a`, `b`를 입력받는다.
* 전역 변수는 사용하지 않는다.
* `calc()` 함수를 통해 `a + b`, `a - b` 두 결과를 모두 얻는다.
* `calc()` 함수의 반환값은 `void`이다.
* `calc()` 함수 안에는 출력문이 없어야 한다.
* 출력은 `main()`에서 한다.

**[입력 예시]**

```text
3 2
```

**[출력 예시]**

```text
합 : 5, 차 : 1
```

---

## 2. 최종 코드

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>

void calc(int a, int b, int* sum, int* sub)
{
	*sum = a + b;
	*sub = a - b;
}

int main()
{
	int a, b;
	int sum, sub;

	printf("? ");
	scanf("%d %d", &a, &b);

	calc(a, b, &sum, &sub);

	printf("합 : %d, 차 : %d", sum, sub);

	return 0;
}
```

---

## 3. 핵심 로직 분석

이번 문제의 핵심은 `return` 없이 함수 밖의 변수에 여러 결과를 저장하는 것이다.

이전 문제에서는 함수가 계산 결과 하나를 `return`했다.

```c
int max(int a, int b, int c)
{
	int result = a;

	if (b > result)
	{
		result = b;
	}

	if (c > result)
	{
		result = c;
	}

	return result;
}
```

이 방식은 결과가 하나일 때 적합하다.

하지만 이번 문제에서는 결과가 두 개다.

```text
합
차
```

C 함수의 `return`은 기본적으로 하나의 값만 돌려줄 수 있으므로, 이번 문제에서는 포인터 매개변수를 사용한다.

---

## 4. `void calc()`의 의미

```c
void calc(int a, int b, int* sum, int* sub)
```

이 함수에서 `void`는 반환값이 없다는 뜻이다.

즉, `calc()`는 아래처럼 값을 반환하지 않는다.

```c
return result;
```

대신 `sum`, `sub`의 주소를 받아서 그 주소가 가리키는 실제 변수에 값을 직접 저장한다.

```c
*sum = a + b;
*sub = a - b;
```

따라서 `main()`에서는 다음처럼 함수 결과를 변수에 대입하지 않는다.

```c
calc(a, b, &sum, &sub);
```

이 호출문은 다음 의미를 가진다.

```text
a와 b를 calc 함수에 넘긴다.
sum 변수의 주소를 넘긴다.
sub 변수의 주소를 넘긴다.
calc 함수는 그 주소를 이용해 sum과 sub 값을 직접 수정한다.
```

---

## 5. `&`와 `*`의 역할

이번 문제에서 가장 중요한 구분은 `&`와 `*`이다.

`main()`에서 함수를 호출할 때는 변수의 주소를 넘긴다.

```c
calc(a, b, &sum, &sub);
```

여기서:

```text
&sum = sum 변수의 주소
&sub = sub 변수의 주소
```

이다.

반대로 `calc()` 함수 안에서는 포인터가 가리키는 실제 변수에 접근해야 한다.

```c
*sum = a + b;
*sub = a - b;
```

여기서:

```text
sum  = 주소
*sum = 그 주소에 있는 실제 변수
```

이다.

즉, 정리하면 다음과 같다.

```text
main에서 넘길 때는 &
함수 안에서 값을 저장할 때는 *
```

---

## 6. 실행 흐름

입력이 다음과 같다고 하자.

```text
3 2
```

`main()`에서 입력을 받으면:

```text
a = 3
b = 2
```

그다음 함수 호출이 실행된다.

```c
calc(a, b, &sum, &sub);
```

`calc()` 함수 안에서는 다음 계산이 수행된다.

```c
*sum = a + b;
```

즉:

```text
sum = 3 + 2 = 5
```

그리고:

```c
*sub = a - b;
```

즉:

```text
sub = 3 - 2 = 1
```

함수는 `void`이므로 값을 반환하지 않고 종료된다.
하지만 `sum`, `sub` 변수에는 이미 결과가 저장되어 있다.

그래서 `main()`에서 다음 출력이 가능하다.

```c
printf("합 : %d, 차 : %d", sum, sub);
```

---

## 7. 핵심 인사이트

이번 문제는 포인터를 이용해 함수가 여러 결과를 밖으로 전달하는 구조를 연습하는 문제였다.

`return`을 사용하는 함수는 보통 결과 하나를 돌려준다.

```text
return 방식 = 결과 하나 반환
```

하지만 이번 문제처럼 합과 차를 동시에 얻어야 하는 경우에는 포인터 매개변수를 사용한다.

```text
포인터 방식 = 함수 밖 변수의 주소를 받아 직접 수정
```

이번 문제의 핵심 구조는 다음과 같다.

```text
main()
→ a, b 입력
→ sum, sub 변수 준비
→ calc(a, b, &sum, &sub) 호출
→ calc()에서 *sum, *sub에 결과 저장
→ main()에서 sum, sub 출력
```

함수 역할도 명확하게 분리된다.

```text
calc() = 합과 차 계산 후 포인터로 결과 저장
main() = 입력과 출력 담당
```

이번 문제에서 가장 중요한 문장은 다음이다.

```text
main에서 주소를 넘길 때는 &
함수 안에서 그 주소의 실제 값을 바꿀 때는 *
```
