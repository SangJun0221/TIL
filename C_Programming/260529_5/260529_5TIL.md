# 260529_5 C언어 트러블슈팅: `strcpy()`와 `strcat()`으로 이메일 문자열 조립하기

## 1. 문제 요약

사용자로부터 `id`와 `domain`을 입력받아 이메일 주소를 만드는 프로그램 구현.

**[처리 조건]**

* `id`를 문자열로 입력받는다.
* `domain`을 문자열로 입력받는다.
* 최종 이메일은 `id + "@" + domain` 형태로 만든다.
* 문자열 복사에는 `strcpy()`를 사용한다.
* 문자열 연결에는 `strcat()`을 사용한다.
* 최종 이메일을 출력한다.

**[입력 예시]**

```text
ID? sangjun
Domain? gmail.com
```

**[출력 예시]**

```text
sangjun@gmail.com
```

---

## 2. 최종 코드

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <string.h>

int main()
{
	char id[50];
	char domain[50];
	char email[102];

	printf("ID? ");
	scanf("%s", id);

	printf("Domain? ");
	scanf("%s", domain);

	strcpy(email, id);
	strcat(email, "@");
	strcat(email, domain);

	printf("%s", email);

	return 0;
}
```

---

## 3. 핵심 로직 분석

이번 문제의 핵심은 여러 문자열을 하나의 문자열로 조립하는 것이다.

최종 이메일 형식은 다음과 같다.

```text
id + "@" + domain
```

예를 들어 입력값이 다음과 같다면:

```text
id = "sangjun"
domain = "gmail.com"
```

먼저 `strcpy()`로 `id`를 `email`에 복사한다.

```c
strcpy(email, id);
```

결과:

```text
email = "sangjun"
```

그다음 `strcat()`으로 `email` 뒤에 `"@"`를 붙인다.

```c
strcat(email, "@");
```

결과:

```text
email = "sangjun@"
```

마지막으로 `domain`을 뒤에 붙인다.

```c
strcat(email, domain);
```

결과:

```text
email = "sangjun@gmail.com"
```

---

## 4. `strcpy()`의 의미

`strcpy`는 **string copy**의 줄임말이다.

한국어로는 **문자열 복사**라고 보면 된다.

```c
strcpy(email, id);
```

이 코드는 `id`에 들어 있는 문자열을 `email`에 복사한다는 뜻이다.

즉, 문자열을 처음 만들 때 시작값을 넣는 용도로 사용한다.

```text
strcpy = 문자열을 처음 복사해서 넣기
```

---

## 5. `strcat()`의 의미

`strcat`은 **string concatenate**의 줄임말이다.

한국어로는 **문자열 연결** 또는 **문자열 이어붙이기**라고 보면 된다.

```c
strcat(email, "@");
```

이 코드는 기존 `email` 문자열 뒤에 `"@"`를 붙인다는 뜻이다.

```c
strcat(email, domain);
```

이 코드는 기존 `email` 문자열 뒤에 `domain`을 붙인다는 뜻이다.

```text
strcat = 기존 문자열 뒤에 추가로 붙이기
```

---

## 6. `strcpy()`와 `strcat()`의 차이

두 함수의 역할은 다르다.

```text
strcpy() = 문자열을 복사한다
strcat() = 문자열 뒤에 이어 붙인다
```

이번 문제에서는 먼저 `email`에 `id`를 넣어야 하므로 `strcpy()`를 사용했다.

```c
strcpy(email, id);
```

그 후 `"@"`와 `domain`은 이미 만들어진 `email` 뒤에 붙이는 것이므로 `strcat()`을 사용했다.

```c
strcat(email, "@");
strcat(email, domain);
```

따라서 이메일 조립 순서는 다음과 같다.

```text
strcpy → strcat → strcat
```

---

## 7. 배열 크기

이번 코드에서는 다음과 같이 배열을 선언했다.

```c
char id[50];
char domain[50];
char email[102];
```

`email`은 `id`, `"@"`, `domain`, 그리고 문자열 끝 표시인 `'\0'`까지 저장할 수 있어야 한다.

```text
id + "@" + domain + '\0'
```

문자열 배열을 만들 때는 실제 출력될 문자뿐 아니라 마지막의 `'\0'` 공간도 고려해야 한다.

## 8. 핵심 인사이트

이번 문제는 문자열을 새로 조립할 때 `strcpy()`와 `strcat()`을 어떤 순서로 써야 하는지 확인하는 문제였다.

핵심은 다음과 같다.

```text
처음 문자열을 넣을 때는 strcpy()
기존 문자열 뒤에 붙일 때는 strcat()
```

이번 이메일 조립은 다음 흐름으로 정리할 수 있다.

```text
email에 id 복사
-> email 뒤에 "@"
-> email 뒤에 domain
-> 최종 email 출력
```

C에서 문자열 처리 함수를 사용할 때는 다음 헤더가 필요하다.

```c
#include <string.h>
```
