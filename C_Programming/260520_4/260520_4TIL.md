# 260520_4 C언어 트러블슈팅: 배열 초기화 후 후처리 방식으로 조건 카운트하기

## 1. 문제 요약
최대 100개의 정수를 입력받아 배열에 저장하고, 입력이 끝난 뒤 배열을 다시 순회하면서 `60 이상인 수의 개수`를 출력하는 프로그램 구현.

**[처리 조건]**
* 배열 크기는 `100`으로 한다.
* 정수를 계속 입력받는다.
* 입력값이 `-1`이면 입력을 종료한다.
* `-1`은 계산에 포함하지 않는다.
* 입력받으면서 개수를 세지 않는다.
* 입력이 끝난 뒤 배열을 다시 순회하면서 `60 이상인 수`를 카운트한다.

**[입력 예시]**
```text
50
70
80
30
-1
````

**[출력 예시]**

```text
60 이상 개수 : 2
```

---

## 2. 초기 구현

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>

int main()
{
	int a[100];
	int i;
	int count = 0;

	for (i = 0; i < 100; i++)
	{
		a[i] = -1;
	}

	for (i = 0; i < 100; i++)
	{
		scanf("%d", &a[i]);

		if (a[i] == -1)
		{
			break;
		}
	}

	for (i = 0; i < 100; i++)
	{
		if (a[i] != -1)
		{
			if (a[i] >= 60)
				count++;
		}
	}

	printf("60 이상 개수 : %d", count);
}
```

---

## 3. 문제 상황

이번 문제는 입력받으면서 바로 `count++`를 하면 안 되는 조건이 있었다.

따라서 입력 단계에서는 배열에 값만 저장하고, 실제 카운트는 입력이 모두 끝난 뒤 배열을 다시 순회하면서 해야 했다.

또한 입력 개수가 최대 100개로 정해져 있지만, 실제 입력은 `-1`이 나오면 중간에 끝난다.

예를 들어 아래처럼 입력하면:

```text
50
70
80
30
-1
```

실제 데이터는 다음 값들이다.

```text
50, 70, 80, 30
```

나머지 배열 칸은 사용되지 않은 칸이다.
이 미입력 칸을 구분하기 위해 배열 전체를 처음에 `-1`로 초기화했다.

---

## 4. 원인 분석

이번 문제의 핵심은 **입력 단계와 계산 단계를 분리하는 것**이다.

초기화 단계에서는 배열 전체를 `-1`로 채워둔다.

```c
for (i = 0; i < 100; i++)
{
	a[i] = -1;
}
```

이렇게 하면 사용자가 입력하지 않은 배열 칸도 모두 `-1` 상태로 남는다.

그 후 입력 단계에서는 값만 저장한다.

```c
for (i = 0; i < 100; i++)
{
	scanf("%d", &a[i]);

	if (a[i] == -1)
	{
		break;
	}
}
```

여기서는 `count++`를 하지 않는다.
문제 조건상 입력받으면서 개수를 세면 안 되기 때문이다.

마지막으로 후처리 단계에서 배열 전체를 다시 순회한다.

```c
for (i = 0; i < 100; i++)
{
	if (a[i] != -1 && a[i] >= 60)
	{
		count++;
	}
}
```

여기서 `a[i] != -1`은 실제 입력된 값인지 확인하는 조건이고,
`a[i] >= 60`은 카운트 대상인지 확인하는 조건이다.

---

## 5. 수정 과정

처음에는 조건을 중첩해서 작성했다.

**[수정 전]**

```c
if (a[i] != -1)
{
	if (a[i] >= 60)
		count++;
}
```

이 구조도 논리적으로는 맞다.

다만 두 조건은 동시에 만족해야 하므로 `&&` 연산자를 사용해 한 줄로 정리할 수 있다.

**[수정 후]**

```c
if (a[i] != -1 && a[i] >= 60)
{
	count++;
}
```

또한 프로그램 종료 형식을 명확히 하기 위해 마지막에 `return 0;`을 추가했다.

## 6. 최종 코드 (Verified Code)

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>

int main()
{
	int a[100];
	int i;
	int count = 0;

	for (i = 0; i < 100; i++)
	{
		a[i] = -1;
	}

	for (i = 0; i < 100; i++)
	{
		scanf("%d", &a[i]);

		if (a[i] == -1)
		{
			break;
		}
	}

	for (i = 0; i < 100; i++)
	{
		if (a[i] != -1 && a[i] >= 60)
		{
			count++;
		}
	}

	printf("60 이상 개수 : %d", count);

	return 0;
}
```

## 7. 핵심 인사이트 (Takeaway) & Action Item

이번 문제의 핵심은 **배열에 먼저 저장하고, 계산은 나중에 다시 순회하면서 처리하는 후처리 방식**이다.

입력받으면서 바로 `count++`를 하면 더 간단하지만, 문제 조건에서 금지했기 때문에 입력 단계와 계산 단계를 분리해야 했다.

전체 흐름은 다음과 같다.

```text
배열 전체 -1 초기화 -> 입력만 받기 -> 입력 종료 후 배열 재순회 -> 조건 카운트
```

배열을 `-1`로 초기화하는 이유는 사용자가 입력하지 않은 칸을 구분하기 위해서다.

또한 `a[i] != -1 && a[i] >= 60`처럼 조건을 결합하면, 실제 입력값이면서 동시에 60 이상인 값만 정확히 카운트할 수 있다.

* [ ] 문제에서 입력 중 계산을 금지하면 입력 단계와 계산 단계를 분리하기
* [ ] 배열 전체를 `-1`로 초기화하는 이유를 이해하고 사용하기
* [ ] `-1`은 sentinel 값이므로 계산 대상에서 제외하기
* [ ] 후처리 단계에서는 `a[i] != -1`로 실제 입력값인지 먼저 확인하기
* [ ] 조건이 동시에 필요할 때는 `&&`로 결합할 수 있는지 확인하기
