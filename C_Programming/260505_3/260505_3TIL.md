# 260505_2 C언어 트러블슈팅: 역피라미드 출력에서 공백 반복문과 별 반복문 분리하기

## 1. 문제 요약
정수 `a`를 입력받아, 아래로 갈수록 별 개수가 2개씩 줄어드는 역피라미드 형태를 출력하는 프로그램 구현.

**[처리 조건]**
* 입력값은 3 이상의 홀수라고 가정한다.
* 첫 줄에는 `*`를 입력값만큼 출력한다.
* 다음 줄로 내려갈수록 별 개수는 2개씩 감소한다.
* 다음 줄로 내려갈수록 앞 공백은 1개씩 증가한다.
* 마지막 줄에는 `*` 1개만 출력한다.

**[입력 예시]**
```text
5
````

**[출력 예시]**

```text
*****
 ***
  *
```

---

## 2. 초기 구현

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>

int main()
{
	int a;

	scanf("%d", &a);

	for (int i = 1; i <= a; i++) 
	{
		for (int j = a; j >= (a-j)/2; j-=2)
		{
			printf(" ");
		}
		for (int i = 1; i <= a; i += 2)
		{
			printf("*");
		}
		printf("\n");
	}

	return 0;
}
```

---

## 3. 문제 상황

역피라미드 형태를 만들기 위해 중첩 반복문을 작성했지만, 공백과 별의 출력 횟수가 의도대로 제어되지 않았다.

초기 코드에서는 바깥 반복문에서 `i`를 줄 번호처럼 사용하고, 안쪽 별 출력 반복문에서도 다시 `int i`를 선언했다.

또한 공백 출력 반복문의 조건식에 `(a - j) / 2`처럼 반복 변수 `j`가 직접 들어가면서, 공백 개수를 안정적으로 제어하지 못했다.

결과적으로 다음 문제가 발생했다.

* 바깥 반복문과 안쪽 반복문에서 같은 이름의 변수 `i`를 중복 선언함
* 공백 반복문의 조건식이 복잡하고 잘못 설계됨
* 별 출력 반복문이 매 줄마다 필요한 별 개수 `5, 3, 1`을 반영하지 못함
* 공백 출력과 별 출력의 역할이 명확히 분리되지 않음

## 4. 원인 분석

이번 문제의 핵심은 **한 줄을 공백 영역과 별 영역으로 나누어 생각하는 것**이었다.

역피라미드 출력은 단순히 별만 줄어드는 문제가 아니다.
각 줄마다 다음 두 값을 따로 계산해야 한다.

```text
앞 공백 개수
현재 줄의 별 개수
```

입력값이 `5`일 때 필요한 구조는 다음과 같다.

| 줄 | 앞 공백 개수 | 별 개수 |
| - | ------: | ---: |
| 1 |       0 |    5 |
| 2 |       1 |    3 |
| 3 |       2 |    1 |

따라서 반복문도 다음처럼 역할을 나누어야 한다.

```text
바깥 반복문: 한 줄씩 처리
첫 번째 안쪽 반복문: 앞 공백 출력
두 번째 안쪽 반복문: 별 출력
줄바꿈
```

이번 문제에서는 `i`를 줄 번호로 쓰기보다 **현재 줄의 별 개수**로 두는 방식이 더 직관적이었다.

입력값 `5` 기준으로 `i`가 다음처럼 변하면 된다.

```text
i = 5 -> 별 5개
i = 3 -> 별 3개
i = 1 -> 별 1개
```

따라서 바깥 반복문은 다음과 같이 설계할 수 있다.

```c
for (i = a; i >= 1; i -= 2)
```

이때 공백 개수는 아래 공식으로 계산한다.

```text
앞 공백 개수 = (전체 폭 - 현재 줄 별 개수) / 2
```

즉 코드에서는 다음과 같다.

```c
(a - i) / 2
```

## 5. 수정 과정

초기 코드에서 가장 먼저 수정한 것은 반복문 제어 변수의 의미였다.

기존에는 `i`를 줄 번호처럼 사용하려 했지만, 이번 문제에서는 `i`를 **현재 줄의 별 개수**로 사용했다.

**[수정 전]**

```c
for (int i = 1; i <= a; i++) 
{
	...
	for (int i = 1; i <= a; i += 2)
	{
		printf("*");
	}
}
```

**[수정 후]**

```c
for (int i = a; i >= 1; i -= 2)
{
	...
}
```

이렇게 바꾸면 입력값이 `5`일 때 `i`가 `5 -> 3 -> 1`로 변한다.
따라서 별 출력 반복문은 단순히 `i`번 반복하면 된다.

```c
for (int j = 0; j < i; j++)
{
	printf("*");
}
```

공백 출력은 현재 줄의 별 개수 `i`와 전체 폭 `a`의 차이를 이용해 계산했다.

```c
for (int j = 0; j < (a - i) / 2; j++)
{
	printf(" ");
}
```

즉, 최종적으로 한 줄은 다음 순서로 출력된다.

```text
공백 출력 -> 별 출력 -> 줄바꿈
```

## 6. 최종 코드 (Verified Code)

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>

int main()
{
	int a;

	scanf("%d", &a);

	for (int i = a; i >= 1; i -= 2)
	{
		for (int j = 0; j < (a - i) / 2; j++)
		{
			printf(" ");
		}

		for (int j = 0; j < i; j++)
		{
			printf("*");
		}

		printf("\n");
	}

	return 0;
}
```

## 7. 보완 코드: 교수님 예제 스타일

교수님 예제처럼 변수 선언을 함수 앞부분에 모아두는 방식으로 작성하면 다음과 같다.

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>

int main()
{
	int a;
	int i, j;

	scanf("%d", &a);

	for (i = a; i >= 1; i -= 2)
	{
		for (j = 0; j < (a - i) / 2; j++)
		{
			printf(" ");
		}

		for (j = 0; j < i; j++)
		{
			printf("*");
		}

		printf("\n");
	}

	return 0;
}
```

Visual Studio에서는 `for (int i = ...)` 형태도 동작하지만, 교수님 코드 스타일에 맞추려면 `int i, j;`를 위에서 선언하는 방식이 더 안전하다.

## 8. 핵심 인사이트 (Takeaway) & Action Item

역피라미드 출력 문제에서는 `i`를 항상 줄 번호로만 볼 필요가 없다.

이번 문제에서는 `i`를 **현재 줄의 별 개수**로 설정했기 때문에, 별 출력 반복문을 단순하게 작성할 수 있었다.

```text
i = 현재 줄의 별 개수
```

이 관점으로 보면 구조가 단순해진다.

```text
i = 5 -> 공백 0개, 별 5개
i = 3 -> 공백 1개, 별 3개
i = 1 -> 공백 2개, 별 1개
```

공백 개수는 가운데 정렬 공식으로 계산한다.

```text
앞 공백 개수 = (전체 폭 - 현재 줄 별 개수) / 2
```

즉, 코드에서는 다음 식을 사용한다.

```c
(a - i) / 2
```

이번 문제의 핵심 구조는 다음과 같다.

```text
현재 줄 별 개수 설정 -> 앞 공백 출력 -> 별 출력 -> 줄바꿈
```

* [ ] 공백 출력 반복문과 별 출력 반복문을 분리하기
* [ ] 공백 개수는 `(전체 폭 - 현재 줄 별 개수) / 2`로 계산하기
* [ ] 감소형 반복문에서는 시작값, 조건식, 증감식 방향이 일치하는지 확인하기
* [ ] 같은 중첩 반복문 안에서 `i`를 중복 선언하지 않기
