# 260527_2 C언어 트러블슈팅: 합계 계산 함수와 출력 처리 함수 분리하기

## 1. 문제 요약
두 정수 `a`, `b`를 입력받아 다음 세 구간의 합을 출력하는 프로그램 구현.

**[처리 조건]**
* `a`부터 `b`까지의 합을 구한다.
* `1`부터 `a`까지의 합을 구한다.
* `b`부터 `100`까지의 합을 구한다.
* 합을 구하는 함수와 출력하는 함수를 분리한다.
* 합 계산 함수는 출력하지 않고 결과만 `return`한다.
* 출력은 처리 함수에서 진행한다.

**[입력 예시]**
```text
3 7
````

**[출력 예시]**

```text
3~7 합 : 25
1~3 합 : 6
7~100 합 : 5044
```

---

## 2. 최종 코드

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>

int sum(int a, int b)
{
	int s = 0;
	int i;

	for (i = a; i <= b; i++)
	{
		s += i;
	}

	return s;
}

void sum_proc(int a, int b)
{
	int r;

	r = sum(a, b);
	printf("%d~%d 합 : %d\n", a, b, r);

	r = sum(1, a);
	printf("1~%d 합 : %d\n", a, r);

	r = sum(b, 100);
	printf("%d~100 합 : %d\n", b, r);
}

int main()
{
	int a, b;

	printf("? ");
	scanf("%d %d", &a, &b);

	sum_proc(a, b);

	return 0;
}
```

## 3. 핵심 로직 분석

이번 문제의 핵심은 함수의 역할을 분리하는 것이다.

```c
int sum(int a, int b)
```

이 함수는 `a`부터 `b`까지의 합을 계산한다.
출력은 하지 않고, 계산 결과만 `return s;`로 돌려준다.

```c
void sum_proc(int a, int b)
```

이 함수는 `sum()` 함수를 여러 번 호출해서 필요한 구간의 합을 출력한다.

즉, 역할은 다음처럼 나뉜다.

```text
sum()      = 합계 계산 담당
sum_proc() = sum() 호출 + 출력 담당
main()     = 입력 + 전체 처리 호출
```

---

## 4. 함수 호출 흐름

입력이 다음과 같을 때:

```text
3 7
```

`main()`에서 입력을 받은 뒤:

```c
sum_proc(a, b);
```

를 호출한다.

그 후 `sum_proc()` 내부에서 다음 순서로 계산과 출력이 진행된다.

```c
r = sum(a, b);
```

`sum(3, 7)`이 호출되어 `3 + 4 + 5 + 6 + 7 = 25`를 반환한다.

```c
r = sum(1, a);
```

`sum(1, 3)`이 호출되어 `1 + 2 + 3 = 6`을 반환한다.

```c
r = sum(b, 100);
```

`sum(7, 100)`이 호출되어 `5044`를 반환한다.

## 5. 핵심 인사이트

이번 문제에서 중요한 점은 `sum()` 안에서 출력하지 않는다는 것이다.

`sum()`은 계산 결과를 반환하는 함수이고, 출력은 `sum_proc()`에서 담당한다.

이렇게 나누면 같은 합계 계산 로직을 여러 번 재사용할 수 있다.

```text
계산 로직은 sum() 하나로 통일
출력 형식은 sum_proc()에서 관리
```

즉, 함수 분리의 기본은 다음과 같다.

```text
계산 함수 = 결과를 return
처리 함수 = 계산 함수 호출 후 출력
main 함수 = 입력과 전체 흐름 제어
```
