# 260518 C언어 트러블슈팅: 배열 입력에서 `&a[i]` 누락으로 인한 값 저장 오류

## 1. 문제 요약
정수 5개를 입력받아 배열에 저장한 뒤, 그중 `60 이상인 수`만 출력하는 프로그램 구현.

**[처리 조건]**
* 정수 5개를 입력받는다.
* 입력받은 값은 배열 `a[5]`에 저장한다.
* 배열에 저장된 값 중 `60` 이상인 값만 출력한다.
* 출력값은 공백으로 구분한다.

**[입력 예시]**
```text
50 70 30 90 60
````

**[출력 예시]**

```text
70 90 60
```

---

## 2. 초기 구현

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>

int main()
{
	int a[5];

	for (int i = 0; i < 5; i++)
	{
		scanf("%d", a[i]);
	}

	for (int i = 0; i < 5; i++)
	{
		if (a[i] >= 60)
		{
			printf("%d", a[i]);
		}
	}

	return 0;
}
```

---

## 3. 문제 상황

정수 5개를 입력한 뒤, `60` 이상인 값이 정상적으로 출력되지 않았다.

처음에는 조건문 문제처럼 보였지만, 실제 원인은 입력 과정에 있었다.

초기 코드에서는 다음과 같이 작성했다.

```c
scanf("%d", a[i]);
```

하지만 `scanf`는 입력값을 저장할 **변수의 주소**를 필요로 한다.

배열의 `i`번째 칸에 값을 저장하려면 `a[i]`가 아니라 `&a[i]`를 전달해야 한다.

---

## 4. 원인 분석

배열의 각 칸은 일반 변수처럼 값을 저장할 수 있는 공간이다.

예를 들어:

```c
int a[5];
```

는 정수 5개를 저장할 수 있는 배열이고, 각각의 칸은 다음처럼 접근한다.

```text
a[0], a[1], a[2], a[3], a[4]
```

입력받을 때는 각 칸에 값을 저장해야 하므로, `scanf`에 해당 칸의 주소를 넘겨야 한다.

```c
scanf("%d", &a[i]);
```

반대로 값을 검사하거나 출력할 때는 주소가 아니라 저장된 값 자체를 사용한다.

```c
if (a[i] >= 60)
{
	printf("%d ", a[i]);
}
```

즉, 배열 문제에서는 다음 차이를 구분해야 한다.

```text
입력할 때: &a[i]
검사/출력할 때: a[i]
```

초기 코드처럼 `scanf("%d", a[i]);`로 작성하면, 아직 값이 저장되지 않은 `a[i]`의 값을 주소처럼 사용하게 되므로 정상적인 입력 저장이 이루어지지 않는다.

---

## 5. 수정 과정

입력 부분에서 `a[i]` 앞에 주소 연산자 `&`를 추가했다.

**[수정 전]**

```c
scanf("%d", a[i]);
```

**[수정 후]**

```c
scanf("%d", &a[i]);
```

또한 출력할 때 숫자들이 붙어서 출력되지 않도록 `%d` 뒤에 공백을 추가했다.

**[수정 전]**

```c
printf("%d", a[i]);
```

**[수정 후]**

```c
printf("%d ", a[i]);
```

## 6. 최종 코드 (Verified Code)

```c
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>

int main()
{
	int a[5];

	for (int i = 0; i < 5; i++)
	{
		scanf("%d", &a[i]); // 입력 시 주소 전달
	}

	for (int i = 0; i < 5; i++)
	{
		if (a[i] >= 60)
		{
			printf("%d ", a[i]); // 출력값 사이 공백
		}
	}

	return 0;
}
```

## 7. 핵심 인사이트 (Takeaway) & Action Item

배열 입력 문제에서 `scanf`는 배열의 특정 칸에 값을 저장해야 하므로, 해당 칸의 주소를 넘겨야 한다.

```c
scanf("%d", &a[i]);
```

반면 조건 검사나 출력에서는 배열 칸에 저장된 값을 사용하면 된다.

```c
a[i]
```

이번 문제의 핵심 구조는 다음과 같다.

```text
배열 선언 -> 반복 입력 -> 배열 순회 -> 조건 검사 -> 출력
```

배열을 처음 다룰 때는 `a[i]`와 `&a[i]`의 차이를 반드시 구분해야 한다.

**[다음부터 체크할 것]**

* [ ] 배열 입력 시 `scanf("%d", &a[i])` 형태인지 확인하기
* [ ] 배열 검사/출력 시에는 `a[i]`를 사용하는지 확인하기
* [ ] 배열 인덱스는 `0`부터 시작한다는 점 기억하기
* [ ] 크기가 `5`인 배열은 `a[0]`부터 `a[4]`까지만 사용하기
* [ ] 출력값이 붙지 않도록 필요한 경우 `printf("%d ", a[i])`처럼 공백 넣기
